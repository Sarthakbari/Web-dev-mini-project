# 🌐 Web Development Mini Projects

A collection of beginner-friendly web development mini projects built using **HTML**, **CSS**, and **JavaScript**. These projects helped me strengthen my frontend development skills by practicing UI design, animations, DOM manipulation, and responsive layouts.

---

## 🚀 Live Demo

🔗 **BMI Calculator:**  
https://bmi-calc-project.vercel.app

🔗 **Mini Projects Collection:**  
https://mini-web-development-projects-hqbg.vercel.app

---

## 📂 Projects Included

| Project | Description |
|---------|-------------|
| 🧮 BMI Calculator | Calculates Body Mass Index based on user input and displays health status. |
| ➕ Calculator | A fully functional calculator performing basic arithmetic operations. |
| 🎨 Color Changing | Changes background or element colors dynamically using JavaScript. |
| 🧊 Cube Design | A creative 3D cube designed using HTML and CSS. |
| ⏰ Digital Clock | Displays the current time in real-time using JavaScript. |
| 👻 Ghost Animation | CSS animation of a floating ghost with smooth transitions. |
| 💳 Payment Form | Responsive payment form with clean UI and input validation. |
| 💍 Ring Animation | Animated ring effect created using CSS keyframes. |
| 🔺 Triangle Animation | Creative animated triangle design using pure CSS. |
| 🌈 Colorful Spinner | Loading spinner animation with vibrant colors. |
